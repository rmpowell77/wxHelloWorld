# wxHelloWorld.git
This project contains materials and example code used for my set of talks on Declarative Programming.

There are different versions of the talk, and this repository catalogs the code used in those versions.

## Live Demo examples

The tags Example1, Example2, and Example3 show how to get a basic UI example up and running.
